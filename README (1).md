# ☕ Praticando Java

Repositório com os projetos práticos desenvolvidos ao longo da minha jornada de aprendizado em Java orientado a objetos, cobrindo desde os fundamentos até conceitos avançados de POO.

---

## 📁 Estrutura do Repositório

```
Praticando Java/
├── Variaveis e tipos/
├── POO_pratica/
├── Encapsulamento/
└── Heranca_Polimorfismo_Interfaces/
```

---

## 📚 Módulos

### 🔢 Variáveis e Tipos
Fundamentos da linguagem Java com foco em variáveis, tipos de dados e operações.

**Habilidades desenvolvidas:**
- Desenvolver programas em Java utilizando variáveis, operações matemáticas e estruturas condicionais
- Realizar conversões de tipos e manipular dados
- Criar soluções para problemas do cotidiano aplicando lógica de programação e boas práticas de codificação

---

### 🧩 POO Prática — Classes, Atributos e Métodos
Introdução à Programação Orientada a Objetos com foco na estrutura básica de classes.

**Habilidades desenvolvidas:**
- Criar e manipular classes para representar entidades do mundo real, organizando dados e comportamentos de forma estruturada
- Implementar métodos que encapsulam lógicas específicas, desde cálculos simples até validações condicionais

---

### 🔒 Encapsulamento
Aplicação do princípio de encapsulamento para garantir a integridade e segurança dos dados.

**Habilidades desenvolvidas:**
- Criar e manipular classes para representar entidades do mundo real, organizando dados e comportamentos de forma estruturada
- Implementar métodos que encapsulam lógicas específicas
- Controlar o acesso a atributos usando modificadores como `private` e métodos `getters`/`setters`, garantindo a integridade dos dados

---

### 🏛️ Herança, Polimorfismo e Interfaces
Conceitos avançados de POO para criação de hierarquias de classes reutilizáveis e flexíveis.

**Habilidades desenvolvidas:**
- Criar e manipular classes e objetos para modelar entidades do mundo real com atributos e comportamentos específicos
- Aplicar herança e polimorfismo para reutilizar código e criar hierarquias de classes com comportamentos especializados
- Implementar interfaces para definir contratos que garantam consistência e flexibilidade em diferentes contextos

---

## ▶️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/praticando-java.git
   ```

2. Abra o projeto no VS Code (ou na IDE de sua preferência)

3. Navegue até o módulo desejado e execute o arquivo `.java` principal
